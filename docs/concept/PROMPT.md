# Промт: концепт интерфейса Swept — «Orbit»

> Готовый промт для дизайнера-человека или ИИ (Claude / v0 / Cursor). Все плейсхолдеры
> шаблона заполнены под реальный продукт — Swept 1.2.0.

---

## Роль

Ты — ведущий UX/UI-дизайнер с фокусом на футуристичные, инновационные и нешаблонные
интерфейсы. Ты умеешь делать «вау» без потери юзабилити: сначала сценарий и иерархия,
потом форма. Ты ненавидишь дефолтные дашборды, но ещё сильнее — красивые интерфейсы,
в которых невозможно работать.

## Продукт

**Swept 1.2.0** — утилита обслуживания Windows 10/11 в одном окне. Пять модулей:

| Модуль | Что делает |
|---|---|
| **Cleanup** | Освобождает диск: 15 категорий (temp, кэши браузеров, кэш Windows Update, корзина, логи, дампы, кэши игровых лаунчеров). Сначала анализ, удаление — только по подтверждению. |
| **Install** | Каталог из 24 программ + 12 пакетов Visual C++ (2005–2022). Скачивание с CDN вендоров, проверка подписи или SHA-256, тихая установка. |
| **Optimize** | 12 безопасных твиков Windows (телеметрия, план питания, фоновые приложения, Game DVR, деблоат) с точкой восстановления перед изменениями. |
| **Schedule** | Тихая автоочистка: ежедневно/еженедельно, сухой прогон, точка восстановления, опциональная задача Windows Task Scheduler (headless). |
| **Log** | Полная история каждого удалённого файла и изменённой настройки с причинами пропусков. |

Технически: Python + CustomTkinter, тёмная тема, RU/EN, окно 1060×740 (минимум 960×660),
exe без установки Python. Программа бесплатная, open source, **без телеметрии и рекламы**.

## Целевая аудитория

Продвинутые пользователи Windows 25–45: геймеры, IT-энтузиасты, разработчики, сисадмины
«на полставки» в своей семье. Они перепробовали десяток «чистильщиков» и **не доверяют**
им: боятся, что программа удалит лишнее, поставит тулбар или продаст данные.

Что для них важно: **прозрачность** (видеть, что именно будет удалено), **контроль**
(ничего без подтверждения), **скорость** (не кликать 12 экранов), **уважение к глазу**
(тёмная тема, никакой аляпистости).

## Задача

Спроектировать главный экран и дизайн-систему Swept так, чтобы интерфейс **выглядел как
инструмент профессионала, а не как «оптимизатор из 2010-х»**. Уникальность — в навигации
и языке визуальных состояний, а не в декорациях.

## Визуальный стиль (обязательные рамки)

- **Направление:** glassmorphism + «precision lab». Никакого плоского Material/iOS.
  Панели — матовое стекло над глубоким фоном, но без «мыльной» размытости: резкие тонкие
  обводки, честная сетка, читаемая типографика.
- **Палитра (использовать ровно эти токены):**
  - фон: чернильно-фиолетовый `#07050D` → `#150E24`
  - акцент 1: неоновый мятный `#57FFC6`
  - акцент 2: электрический лиловый `#A98BFF`
  - текст: пиксельно-белый `#F2EFFF`, приглушённый `rgba(242,239,255,.46)`
  - предупреждение: янтарный `#FFB86B`, опасность: коралловый `#FF6B81`
  - **Запрещено:** корпоративный синий, любые градиентные «закаты», кислотные пары.
- **Типографика:** UI — Segoe UI Variable / Inter; цифры и служебные подписи — моноширинный
  (Cascadia Code / SF Mono) с трекингом `.18em` и uppercase для микро-лейблов. Крупные
  числа — табличные цифры, чтобы не «прыгали» при анимации.
- **Формы:** скругления 20 px у панелей, 999 px у чипов, 14 px у кнопок. Асимметричная
  сетка: узкий левый рельс телеметрии, широкая сцена, узкий правый рельс журнала,
  нижняя контекстная лента. Никаких симметричных «карточек в ряд».
- **Материалы:** стекло `rgba(255,255,255,.055)` + обводка `rgba(255,255,255,.10)` +
  внутренняя световая кромка `inset 0 1px 0 rgba(255,255,255,.06)`. Глубина — за счёт
  свечения и тени, а не за счёт рамок.

## Навигация — главное отличие

**Никаких вкладок сверху.** В центре — «ядро» (живой орб), вокруг него по орбите —
5 узлов-модулей. Взаимодействие:

- клик по узлу → орбита доворачивается, выбранный узел встаёт в верхнюю точку, панель
  модуля «разворачивается» из узла (FLIP-переход, 600–700 мс, easing `cubic-bezier(.2,.8,.2,1)`);
- наведение → сегмент орбиты подсвечивается, узел приподнимается с параллаксом;
- клавиатура → Tab по узлам, Enter — выбор (доступность обязательна);
- лента внизу — **контекстные действия выбранного модуля**, а не глобальное меню.

## Главный экран — структура

1. **Хедер (68 px):** логотип-марка + `SWEPT` (трекинг .22em), чип версии `v1.2.0`,
   переключатель языка EN/RU (морфящая пилюля), чип прав администратора.
2. **Левый рельс (276 px) — телеметрия:** заполненность диска (полоса + число), размер
   `%TEMP%`, корзина, статус точки восстановления, мини-спарклайн последних очисток.
3. **Центр — сцена:** орб-ядро с радиальным прогрессом и живым счётчиком «сколько можно
   освободить»; вокруг — орбита с 5 узлами; за орбами — поле частиц (canvas), реагирующее
   на действия.
4. **Правый рельс (300 px) — «бортовой журнал»:** последние операции с временем, иконкой
   типа и результатом (удалено/пропущено/ошибка).
5. **Нижняя лента:** название модуля + одна строка сути, чипы-категории (шестиугольные),
   справа — основная и вторичная кнопки (`ANALYZE` / `CLEAN` для очистки и т.д.).

## Микро-взаимодействия (обязательный минимум)

1. **Warp:** выбор модуля — орбита поворачивается, узел «взлетает» в центр, панель
   перетекает в него.
2. **Scan wave:** «Анализ» — радиальная волна проходит по сцене, частицы ускоряются,
   счётчик крутится одометром до реального значения.
3. **Vacuum:** «Очистить» — частицы закручиваются в ядро, счётчик идёт вниз, ядро
   перекрашивается из кораллового в мятный, в журнале появляются строки.
4. **Magnetic clock:** в модуле Schedule — 24-часовой радиальный циферблат; тянешь дугу,
   она прилипает к 15-минутным слотам с мягким «щелчком» масштаба.
5. **Peek:** долгое нажатие на категорию — полупрозрачный оверлей с точными путями,
   которые будут затронуты (прозрачность как UX, а не как маркетинг).
6. **Parallax tilt:** сцена слегка наклоняется за курсором (макс. 2–3°), частицы реагируют
   с задержкой.
7. **Опасные состояния:** если выбрана системная категория без прав администратора —
   чип становится янтарным, лента объясняет причину прямо в строке.

## Состояния и крайние случаи

- пусто (нечего чистить) — ядро спокойное, мятное, счётчик `0 B`, вместо кнопки — «всё чисто»;
- идёт операция — блокировка повторного запуска, прогресс на ядре, кнопки в состоянии busy;
- ошибка доступа — строка в журнале с причиной, без модальных окон;
- RU/EN — переключение мгновенное, без перезагрузки, тексты не ломают сетку.

## Ограничения

- Разрешение: 1060×740 (минимум 960×660), десктоп Windows; мобильная версия не нужна.
- Контраст текста ≥ 4.5:1; интерактивные элементы ≥ 40×40 px.
- Никаких эмодзи в интерфейсе — только векторные иконки (24 px, stroke 1.5).
- Не использовать клише «чистильщиков»: метёлки, блёстки, щиты-«антивирусы», 3D-шестерёнки.
- Анимации не должны мешать: всё уважает `prefers-reduced-motion`.

## Формат вывода

**Вариант 2 (основной):** один самодостаточный HTML-файл с React 18 (UMD) + Tailwind (CDN),
без сборки, открывается двойным кликом. Все переходы — CSS-транзишены и
`requestAnimationFrame`; частицы — `<canvas>`; данные — мок-объект в начале файла.

**Дополнительно (кратко):** таблица дизайн-токенов (цвет/типографика/радиусы/тени) и
список компонентов с состояниями (default / hover / focus / active / busy / disabled).

## Критерии приёмки

1. С первого взгляда понятно, что это инструмент, а не игра, — но он выглядит не как всё.
2. Все 5 модулей доступны за один клик из любого состояния.
3. Любое действие имеет видимую обратную связь ≤ 100 мс.
4. Ни один экран не требует объяснения дольше одной строки.
5. Код открывается и работает без интернета (кроме CDN-подключений) и без консольных ошибок.
